# Analytics SDK & Dashboard

A simple analytics system that tracks website activity and server-side events using a sample restaurant website.

## Features
- Track page views and user interactions.
- Record successful demo orders.
- Store events locally using SQLite.
- View analytics through an interactive dashboard.
- Filter events by date.

## Tech Stack
- JavaScript, HTML, CSS
- Node.js
- SQLite (sql.js)

## Run Locally

```bash
npm install
npm start
```

Open `http://localhost:3000` for the restaurant website and `http://localhost:3000/dashboard.html` for the analytics dashboard.

## Testing

```bash
npm test
```
